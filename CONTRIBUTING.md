# Contributing

Contributions to the team-facing LARS WPILib library are welcome.

Please do not submit Pennington Laboratories firmware, private hardware files, manufacturing files, credentials, or other proprietary material.

Before opening a pull request:

1. Build the project successfully.
2. Run the test suite.
3. Add or update tests for protocol changes.
4. Keep public API changes intentional and documented.
5. Do not change CAN API identifiers without updating the protocol documentation.

For hardware or product support, contact Pennington Laboratories.

# LARS-WPILib

Official WPILib library for the Pennington Laboratories LARS (Limit Adaptive Ranging System) sensor.

LARS is an FRC CAN distance and limit sensor designed for mechanism protection, ranging, and target/field-element detection.

## Status

This repository contains the team-facing WPILib API. LARS firmware and proprietary hardware source are not included.

The CAN protocol is intentionally isolated in `LARSCAN` so protocol changes do not leak into the public API.

## Supported WPILib

Target: WPILib 2026.

WPILib 2027 support will be released separately after the 2027 API stabilizes.

## Installation

Once the vendor Maven repository is published, teams can install LARS through:

WPILib VS Code → Manage Vendor Libraries → Install New Libraries (Online)

The vendor JSON will be hosted at:

`https://pennington-laboratories.github.io/LARS-WPILib/PenningtonLabsLARS.json`

## Basic usage

```java
import com.penningtonlabs.lars.LARS;

LARS lars = new LARS(0);

// Requests one fresh measurement. It does not create a periodic CAN stream.
lars.requestDistance();

// Returns the most recently received measurement.
double distanceMm = lars.getDistanceMillimeters();

if (lars.isMeasurementValid()) {
    // Use distanceMm
}
```

## Limit mode

```java
lars.setMode(LARSMode.LIMIT);
lars.requestLimitState();

if (lars.isForwardLimitHit()) {
    // Forward mechanism limit reached
}

if (lars.isReverseLimitHit()) {
    // Reverse mechanism limit reached
}
```

## Design

The public API deliberately separates CAN requests from cached reads:

- `request...()` sends CAN traffic.
- `get...()` reads the latest cached value.
- No CAN traffic is generated by a getter.
- No periodic CAN traffic is enabled by default.

This prevents accidental CAN bus flooding and makes the communication behavior explicit.
